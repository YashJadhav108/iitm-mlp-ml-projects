Download from the Kaggle competition **heavy-equipment-selling-price-prediction-challenge** and place:

```
data/train.csv
data/test.csv
data/sample_submission.csv
data/metadata.csv
```

Then change the paths in the notebook from `/kaggle/input/competitions/heavy-equipment-selling-price-prediction-challenge/` to `data/`.

Or, on Kaggle, attach the competition to a new notebook and upload `heavy_equipment_price_prediction.ipynb` unchanged.
